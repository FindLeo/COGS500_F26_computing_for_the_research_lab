# Sources and document provenance

## Test documents

- `git_slides.pptx`: University of Utah CHPC, **Using Git for Version Control**. [Source page](https://www.chpc.utah.edu/presentations/IntroGit.php) · [PowerPoint](https://www.chpc.utah.edu/presentations/git.pptx). Course-related version-control training with 66 slides.
- `unix_slides.pptx`: Steven Morgan, Melbourne Bioinformatics, University of Melbourne, **Introduction to Unix**. [Source page](https://mbite.mdhs.unimelb.edu.au/tutorials/unix/unix/) · [PowerPoint](https://mbite.mdhs.unimelb.edu.au/tutorials/unix/media/unix_intro_slides.pptx). Archived workshop with 22 slides; selected as a conversion sample.
- `rdm_quiz.docx`: Digital Curation Centre, **RDM quick quiz**, Cardiff Metropolitan University workshop, 19 November 2014. [Source page](https://www.dcc.ac.uk/events/workshops/introduction-research-data-management-and-data-management-plans) · [Word document](https://www.dcc.ac.uk/sites/default/files/documents/events/workshops/Cardiff-Met/Funder%20requirements%20quiz.docx). Historical sample; do not treat its funder policies as current guidance.
- `project_proposal.docx`: unchanged copy of the user's `MarkItDown_Project_Proposal_Si-Yang_Liu.docx`, prepared with AI assistance.
- `git_cheatsheet.pdf`: unchanged copy of the existing course workspace file `git-cheatsheet.pdf`; GitHub Education is the publisher. [Publisher reference](https://education.github.com/git-cheat-sheet-education.pdf).
- `datalad_cheatsheet.pdf`: unchanged copy of `M7_datalad-cheatsheet.pdf`; [DataLad Handbook cheatsheet resource](https://handbook.datalad.org/en/inm7/basics/101-136-cheatsheet.html) provides publisher context; the tested copy came from the course workspace.

The external decks cover course topics; they are not instructor-provided COGS 500 slides. Original filenames/URLs, byte sizes, retrieval timestamps, and content hashes are recorded in `source_inventory.json`. No source files have been edited.

## Software documentation consulted

- [Microsoft MarkItDown](https://github.com/microsoft/markitdown): documents supported formats, format-specific extras, and CLI output options. Its intended use is text analysis, so visual fidelity must be evaluated rather than assumed.
- [Pixi manifest reference](https://pixi.prefix.dev/latest/reference/pixi_manifest/): used to declare channels, platforms, Python, PyPI dependencies, and the conversion task.
